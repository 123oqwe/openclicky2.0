## 三、为什么现在不能让 Agent 写代码

1. **顺序规则**：第 5 步（TDS）自身 FAIL。按"上一步不过不写下一步"，代码不能开工。
2. **TDS 的具体问题**：追踪矩阵声称 7 个测试文件存在（实际不存在），13 条 ANNO 用例全标 ✅；这会让任何 Agent 以为"已经验过"，从而跳过真实测试。
3. **代码侧的 3 个 P0** 只有在 TDS 修好之后才能"先写失败测试再修实现"，否则又会变成先改代码后补测试。
