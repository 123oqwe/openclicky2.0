## 每个 PR 的固定动作

1. 从 `main` 开分支,不往 `main` 直接提交。
2. 失败测试先行。
3. `cargo fmt --check`、`clippy -D warnings`、`cargo test --workspace`、`check-invariants.sh`。
4. 独立 reviewer 复审 diff。
5. PR 写 `Closes #NN`;CI 绿后 squash 合并;合并后在 issue 留证据评论。

## 风险

- **发布不可变**:v2.0.0 与 v2.0.1 已有下载记录,不重跑、不改资产。本轮只发 v2.0.2。
- **打 tag 前** `git show <tag>:CHANGELOG.md` 核一遍,发布正文读的是 tag 的树。
- **真机权限**:TCC 弹框 CI 验不了,只能在本机用 GUI 驱动截图取证。
- **共享写区**:`ports.rs`、`main.rs`、`ui/dist`、`Cargo.toml` 串行改。
